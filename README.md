# План до родов

Личный планер: цели по шагам, план дня, ритм привычек.
Работает как приложение на главном экране телефона и без интернета.
Данные хранятся только на устройстве, в репозиторий они не попадают.

## Как выложить на GitHub Pages

1. Зайди на github.com и войди в аккаунт.
2. Нажми «+» → **New repository**. Название, например, `plan`. Видимость **Public**. Нажми **Create repository**.
3. На странице репозитория нажми ссылку **uploading an existing file**.
   Перетащи **все файлы из этой папки** (не саму папку) и нажми **Commit changes**.
4. Открой **Settings → Pages**. В **Source** выбери **Deploy from a branch**,
   ветку **main**, папку **/ (root)** и нажми **Save**.
5. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/plan/`.

## Как поставить на главный экран

- **iPhone:** открой адрес в Safari → «Поделиться» → «На экран «Домой»».
- **Android:** открой адрес в Chrome → меню ⋮ → «Добавить на главный экран».

Дальше всегда открывай планер с иконки. На iPhone у приложения с иконки
своё хранилище, отдельное от Safari.

## Как перенести данные из версии в Claude

1. В старом планере в Claude: вкладка «Итоги» → «Скачать копию».
2. В новом планере (открытом с иконки): «Итоги» → «Восстановить из копии» → выбери файл.

## Важно

- Раз в неделю сохраняй копию («Итоги» → «Скачать копию»). Если удалить
  приложение или очистить данные браузера, восстановить всё можно только из копии.
- Чтобы обновить планер, загрузи новый `index.html` в репозиторий поверх старого.
  Данные при этом не пропадут.
